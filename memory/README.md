# 공식 기억 저장소

- `global/shared/profile.md`: 모든 페르소나가 읽는 안정적인 공통 사실
- `global/journals/<persona>/`: 페르소나별 관점으로 기록한 승인된 기억
- `projects/<project-id>/shared/`: 한 게임 프로젝트에 공통인 결정
- `projects/<project-id>/journals/<persona>/`: 프로젝트별 개인 관점
- `retractions/`: 기존 기억을 활성 문맥에서 제외하는 철회 표식

기억 파일은 `persona memory add`가 만들고 `persona sync`가 원격과 동기화합니다. 수동으로 비밀정보를 추가하지 마세요.
